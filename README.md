## Feature Highlights

### Monitoring & Analytics
- **Real-time overview** — mentions, engagement-weighted sentiment, negative share, sentiment by country & platform, dominant negative aspects, and emerging topics (7d vs previous period)
- **Country intelligence** — interactive world map of estimated mention location with per-country drill-down (trends, topics, hourly pattern, top evidence); Google Play reviews provide exact country signals
- **Topics & trends** — emerging topic detection with momentum deltas
- **Journey funnel** — awareness → consideration → onboarding → usage → loyalty stages with sentiment per stage and weakest-stage callout
- **Timeline replay** — scrub through time and watch sentiment move across countries on an animated map (`/replay`)
- **Correlation insights** — what moves sentiment: complaint bursts, app ratings, weekday patterns (Pearson r over daily aggregates, `/insights`)

### Competitive & Influencer Intelligence
- **Competitor benchmark** — share of voice, sentiment, and aspect matrix vs Exness / IQ Option / OctaFX, plus switcher detection from real posts, filterable by country (`/competitors`)
- **KOL radar** — authors ranked by influence (engagement × frequency × negative impact, boosted by channel reach); high-score negative authors are reputation risks, positive ones are advocacy candidates (`/kol`)
- **App version pain points** — Google Play reviews grouped by release version to spot regressions introduced by a specific release (`/versions`)

### AI Features
- **Ask your market** — analytics chat with LLM tool-calling over SQL aggregations; answers are backed by real data, not guesses
- **Hybrid search** — keyword (Postgres FTS) + semantic (pgvector) search with metadata filters (country, sentiment, source, brand, time range)
- **Response copilot** — AI-drafted replies in the user's own language, with tone, severity, and rationale; high-severity items escalate to the ticket queue
- **Auto-FAQ** — FAQ generated by AI from real user questions, in the same language users write in (`/faq`)
- **Inline translation** — one-click translation for non-English mentions

### Alerts & Reporting
- **Crisis alerts** — z-score anomaly detection on volume & sentiment per country/topic, with severity, incident timeline, and automatic Telegram notifications for high/critical alerts (`/alerts`)
- **Weekly PDF report** — automated report every Monday 06:00, archived and downloadable from the dashboard (`/reports`)

### Operations & Quality
- **Keyword management** — edit monitored queries per source from the UI (`/keywords`)
- **Manual data grab** — trigger a fetch for any source on demand
- **Cost observability** — every LLM request recorded in `llm_usage` and shown at `/costs`; tiered models keep ~95% of classifications on the cheap model
- **Golden dataset eval** — run `pnpm eval` to measure sentiment/aspect/topic accuracy (covers ID/EN slang) whenever prompts or models change
- **Dedupe & anti-bot** — content hash + spam heuristics before analytics

## Stack

- **pnpm monorepo** — full Node.js + TypeScript (no Python)
- **PostgreSQL + pgvector** (FTS + semantic search), **Redis + BullMQ** (pipeline & cron)
- **Provider-agnostic LLM** (OpenAI-compatible SDK, base URL + model via `.env`)
- **Next.js 14 + Tailwind + Recharts + react-simple-maps** for the dashboard

## Structure

```
apps/
  web/          dashboard + API routes (Next.js)
  worker/       pipeline worker (BullMQ) + cron + backfill CLI
packages/
  core/         schema, migrations, normalizer, enrichment, aggregation,
                search, anomaly, report, chat, copilot, benchmark, kol,
                insights, replay, versions, faq
  connectors/   reddit, youtube, google play, tavily
  llm/          tiered OpenAI-compatible client (cheap/strong) + cost tracking
```

## Setup

```bash
pnpm install
pnpm docker:up        # postgres(+pgvector) + redis
pnpm migrate          # core schema
pnpm seed             # (optional) 60-day synthetic demo data — dashboard
                      # comes alive instantly, no API key needed
pnpm dev:web          # dashboard at http://localhost:3000
pnpm dev:worker       # pipeline worker + cron
```

Copy `.env.example` to `.env` and fill in the API keys you need.

## Pipeline

`fetch (cron per source) → normalize+dedupe (ingest) → enrich (tiered LLM: language → sentiment/aspect → topic → journey_stage) → location estimate (heuristics: exact gplay country, language, subreddit/domain) → embedding (pgvector) → SQL aggregation`

Anomaly detection (z-score on volume & sentiment per country/topic) → alert + severity + timeline + Telegram. Weekly PDF report every Monday 06:00.

## Data sources (Phase 1 — all free)

| Source | Method | Notes |
|---|---|---|
| Reddit | OAuth app-only (100 QPM) | link+comment search, incremental cursor |
| YouTube | Data API v3 (10k units/day) | search (100 units) + commentThreads (1 unit), quota tracking |
| Google Play | scraper per country+language | **strongest location signal** (exact country), rating, app version |
| Web | Tavily (1000 credits/month) | topic=news, days param |

X API & TikTok Research API: Phase 3 backlog (cost/approval).

## Phases

- **Phase 1 (done)** — ingestion, tiered enrichment, hybrid search, journey funnel, crisis alerts, weekly PDF report, ask-your-market chat, cost dashboard
- **Phase 2 (done)** — competitor benchmark (`/competitors`: share of voice, aspect matrix, switcher detection), KOL radar (`/kol`), Google Play per-version pain points (`/versions`)
- **Phase 3 partial (free sources)** — response copilot + ticket escalation (`/search` → "Draft reply"), timeline replay map (`/replay`), correlation insights (`/insights`), auto-FAQ (`/faq`), keyword management (`/keywords`). X API / TikTok remain blocked on budget/approval.

## Key commands

```bash
pnpm run fetch reddit             # one-shot fetch for a single source
pnpm backfill --source reddit --days 30
pnpm backfill --source youtube --days 30
pnpm report                       # generate the weekly report now
pnpm --filter @deriv-intel/worker dev   # worker + cron
pnpm eval                         # golden dataset eval (sentiment/aspect/topic accuracy)
pnpm seed                         # synthetic demo data (no API key needed)
```

> Note: always use `pnpm run fetch <source>` — plain `pnpm fetch` is a pnpm built-in (no-op).

## Quality & cost

- **Golden dataset**: `packages/core/src/eval/golden.jsonl` (manually labeled, covers ID/EN slang) — run `pnpm eval` whenever prompts or models change
- **Cost observability**: every LLM request is recorded in the `llm_usage` table and shown on the dashboard at `/costs`
- **Dedupe & anti-bot**: content hash + spam heuristics before analytics
- **Tiered LLM**: cheap model for ~95% of classifications, strong model for reasoning/anomaly explanation/reports/chat
